# bloom-site

Public pages for the Bloom app: the landing page, support and privacy policy.
Published with GitHub Pages at https://womensgym.github.io/bloom-site/

Plain HTML, CSS and JS, no build step. `index.html` + `site.css` + `main.js` is the landing page;
`privacy.html` uses `style.css`. Motion is GSAP + ScrollTrigger from cdnjs, and the page is fully
static without it (reduced motion, or the CDN not loading). Images live in `assets/` as WebP.

The app itself lives in a private repo. Issues here are the public support channel.
